How To Patch Own Version of prometheus.yml to prometheus deployment(Prometheus is read-only)

kubectl delete configmap prometheus-config

kubectl create configmap prometheus-config --from-file=./prometheus.yml

kubectl get configmaps
kubectl get deployments

kubectl patch deployment my-prometheus-server -p '{"spec":{"template":{"spec":{"volumes":[{"name":"config-volume","configMap":{"name":"prometheus-config"}}]}}}}'

/*The kubectl patch deployment command with the provided patch data is used to add a volume to the pod template of the Prometheus server deployment. This volume is named "config-volume" and is populated from the ConfigMap named "prometheus-config". This allows the Prometheus server to access the updated configuration stored in the ConfigMap.
*/
